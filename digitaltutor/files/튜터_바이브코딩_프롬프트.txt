■ T1 수업 전 3분 안전 점검표 (제미나이 Canvas)
너는 학교 디지털 튜터를 돕는 웹 개발자야. 디지털 튜터가 수업 시작 전 3분 동안 교실을 둘러보며 쓰는 '수업 전 3분 안전 점검표' 웹앱을 만들어줘.

[화면]
① 맨 위: 오늘 날짜(자동), 학년·반 입력, 교시 고르기
② 점검 항목 9개를 4묶음으로. 항목마다 큰 버튼 3개 '괜찮아요 ✅ / 조치했어요 🔧 / 보고 필요 ⚠️'
 - 전기·충전: 충전선이 통로를 가로지르지 않는다 / 멀티탭 과부하·물기 없음 / 충전함 문이 동선을 막지 않는다
 - 기기: 파손·발열·부푼 배터리 기기 없음 / 기기 번호와 자리가 맞다
 - 네트워크: 무선 AP 불빛이 초록·파랑이다 / 학습 사이트 접속 확인
 - 이동·자리: 책상 사이 통로가 넓다 / 기기는 책상 안쪽에 둔다
③ 몇 개 점검했는지 보여 주는 진행 막대
④ '보고 문장 만들기' 버튼: '보고 필요' 항목을 모아 "○학년 ○반 ○교시 점검 결과 ~에 문제가 있어 확인이 필요합니다. 현재 ~로 임시 조치 중입니다." 형식의 문장을 만들고 [복사] 버튼
⑤ '새 점검' 버튼. 점검 기록은 브라우저(localStorage)에 날짜별로 저장하고 아래에 목록으로 보여 주기

[조건]
- 휴대폰으로 교실을 돌며 한 손으로 누르기 좋게 큰 버튼, 세로 화면
- 학생 이름은 받지 않기(개인정보)
- 로그인 없이 HTML 파일 하나로 (Tailwind CDN 사용 가능)

■ T1b 고쳐 줘 — 보고 문장과 5계명
고쳐 줘: ① 보고 문장에 항목 이름이 '물기 없음'처럼 정상 상태로 나와. '보고 필요'를 누른 항목은 문제 상황으로 바꿔 써 줘(예: 멀티탭 과부하·물기 있음). ② '조치했어요' 항목은 '~은 조치 완료'로 보고 문장 끝에 덧붙여 줘. ③ 맨 아래에 접었다 펴는 '디지털 수업 5계명' 카드를 넣어 줘(이동할 때는 화면을 보지 않아요 / 전선과 충전기는 허락 없이 만지지 않아요 / 기기는 책상 안쪽에 두어요 / 친구 기기로 로그인하지 않아요 / 이상한 일은 바로 알려요).

■ T2 디지털 친구 그림자 찾기 (1학년)
너는 초등학교 1학년 디지털 수업을 돕는 디지털 튜터야. '디지털은 내 친구 1' 교재의 '똑같은 모양을 찾아요' 활동과 이어지는 '디지털 친구 그림자 찾기' 웹앱을 만들어줘.

[화면]
① 첫 화면: 큰 제목과 '시작하기' 버튼 하나
② 문제 화면: 가운데에 디지털 친구의 검은 그림자 1개, 아래에 그림 카드 3장 중 같은 모양 고르기
 - 디지털 친구 8개: 본체, 모니터, 키보드, 마우스, 스마트 패드, 노트북, 스마트 워치, 인공지능 스피커
 - 그림은 SVG로 직접 그리고, 그림자는 같은 SVG를 검게 칠해서 만들기
③ 맞히면 '딩동댕!' 효과음과 함께 이름을 한국어 음성으로 읽어 주고(speechSynthesis) 별 도장 하나
④ 틀리면 카드가 살짝 흔들리고 "다시 찾아볼까?" — 정답을 바로 알려 주지 않기
⑤ 8문제를 다 풀면 '오늘의 디지털 반장' 축하 화면과 '다시 하기' 버튼

[조건]
- 1학년 눈높이: 글자는 아주 크게(Jua 글꼴), 글은 짧게, 카드는 손가락으로 누르기 쉽게
- 태블릿 가로 화면, 마우스 클릭과 터치 모두
- 로그인·인터넷 저장 없이 HTML 파일 하나로

■ T3 도움 신호등 (1~3학년)
너는 디지털 튜터를 돕는 웹 개발자야. 저학년 학생이 태블릿 화면으로 튜터에게 도움을 요청하는 '도움 신호등' 웹앱을 만들어줘. 튜터가 교실을 돌며 멀리서도 색깔만 보고 누구를 먼저 도울지 알 수 있어야 해.

[화면]
① 첫 화면에 큰 버튼 3개: 🟢 잘하고 있어요 / 🟡 궁금해요 / 🔴 멈췄어요, 도와주세요
② 누르면 화면 전체가 그 색으로 바뀌고 아주 큰 글자와 표정 그림이 나오기
③ 🔴를 누르면 '무엇이 안 되나요?' 그림 버튼 4개: 🔑 로그인 / 🔇 소리 / 📶 인터넷 / 🖼️ 화면이 이상해요 — 고르면 빨간 화면에 그 그림이 크게 함께 보이기
④ 🟡·🔴 화면에는 '튜터 선생님이 곧 와요' 문구와 기다린 시간(초) 표시
⑤ 화면 아무 곳이나 두 번 누르면 처음으로 돌아가기

[조건]
- 1~3학년이 글을 잘 몰라도 쓸 수 있게 그림과 색 위주, 글자는 아주 크게(Jua 글꼴)
- 태블릿 가로·세로 모두, 로그인 없이 HTML 파일 하나로

■ T3b 고쳐 줘 — 겹친 글자와 테두리
고쳐 줘: 빨간 화면에서 '기다린 시간'과 '화면을 두 번 통통 누르면 처음으로 가요' 안내가 겹쳐. 안내 문구는 화면 맨 위 작은 글씨로 옮기고, 오른쪽 위에 큰 '↩ 처음으로' 버튼도 넣어 줘. 그리고 노랑·빨간 화면은 튜터가 멀리서도 알아보게 천천히 깜빡이는 테두리를 넣어 줘.
